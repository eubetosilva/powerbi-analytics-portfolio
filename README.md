# Power BI Analytics Portfolio

Projeto de dashboards e análises de dados utilizando Power BI.

## Estrutura do Projeto

datasets  
Conjunto de dados utilizados nas análises.

dashboards  
Capturas de telas e relatórios criados no Power BI.

## Ferramentas utilizadas

Power BI  
Excel  
GitHub

## Objetivo

Este repositório tem como objetivo apresentar projetos de análise de dados e visualização utilizando o Power BI, demonstrando habilidades em interpretação de dados, construção de dashboards e organização de projetos analíticos.

## Site do portfólio

O repositório inclui um site estático (`index.html`) que apresenta o portfólio. Para visualizar localmente, basta abrir o arquivo `index.html` no navegador.

Para publicar com GitHub Pages:

1. Vá em **Settings > Pages** no repositório.
2. Em **Source**, selecione a branch `main` e a pasta raiz (`/`).
3. Salve — o site ficará disponível em `https://<usuario>.github.io/powerbi-analytics-portfolio/`.

Para adicionar um novo projeto ao site, edite a lista `PROJECTS` em `assets/js/main.js` e coloque as capturas de tela em `dashboards/` e os dados em `datasets/`.
